## Scope
This file governs the `docs/` folder.

## How to work in this folder
- Keep the documentation templates concise but scannable. Favor headings, tables, and bullet lists over prose.
- Leave placeholder text so future editors know what to fill in; do not delete guidance comments unless the section is complete.
- When adding new templates, include a one-line “Purpose” blurb near the top describing when to use it.
- Prefer Markdown that renders well in both GitHub and plain text.
